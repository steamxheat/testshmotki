## Что осознанно оставлено на «после MVP» (§19 ТЗ)

Онлайн-оплата, API-доставка, корзина, промокоды, подписки на размер, импорт из канала,
генерация постов, платные тарифы, публичный веб-каталог, рекомендации, CSV — не входят в
первый релиз согласно ТЗ.

## Заглушки, требующие продакшн-доводки

- **Ресайз изображений**: сейчас отдаётся оригинал из `/uploads`. Для прода — подключить
  обработчик (sharp) или CDN/S3 с трансформациями. Точка расширения — `server/src/lib/upload.ts`.
- **Хранилище**: локальный диск. Абстракция `publicUrl` готова под замену на S3.
- **Бэкап БД и мониторинг**: настраиваются на уровне инфраструктуры при деплое.
- **Политика конфиденциальности и пользовательское соглашение**: тексты добавляются перед
  запуском (в профиле есть пункты-ссылки).
- **Фото в отзывах** (до 3): API принимает `photos: string[]`, UI-загрузка — следующий шаг.
